# 使用说明

> 📦 **从公开仓库克隆的新机器**：本仓库不随附 `runtime/`、`wheels/`、`cache/`、MatrixMedia 安装包等大件，请先按仓库根目录 `DEPLOY.md` 准备运行环境（推荐方式一：系统 Python + `pip install -r requirements.txt` + 安装 MatrixMedia），或还原「自包含离线」目录后再按本说明操作。下文按「自包含目录已就绪」场景编写。

## 一、首次部署（已包含在本目录中）

本目录已经内置：

- 内嵌 Python 3.12 运行时（`runtime/`），目标电脑**不需要**安装 Python；
- 全部 Python 依赖的离线安装包缓存（`wheels/`）；
- MatrixMedia v0.11.0 Windows 安装包（`matrixmedia/`）。

把整个文件夹复制到目标电脑后，双击 `start.bat` 即可：

1. 若 `runtime/` 缺失或依赖不完整，自动调用 `install.bat` 从本地缓存重建（不需要联网）；
2. 若 MatrixMedia 未安装，自动静默安装；
3. 启动 MatrixMedia 并等待其内置 API（端口 30088）就绪；
4. 后台启动调度服务（`pythonw`，无黑窗口）。

## 二、配置账号

打开 MatrixMedia，在「账号管理」中登录需要发布的平台账号（每个平台一次）。

编辑 `config.yaml`，把账号别名映射到手机号：

```yaml
accounts:
  dy-01: "13800138000"
  sph-01: "13900139000"
```

任务文件夹的 `info.json` 只写别名（如 `"account": "dy-01"`），不写手机号，避免分享文件夹时泄露。

## 三、发布任务

### 立即发布

```text
watch/2026-08-11-跑步视频/
├── video.mp4
└── info.json
```

```json
{
  "title": "5 公里晨跑",
  "platforms": ["dy", "sph", "ks"],
  "account": "dy-01",
  "tags": "跑步 晨跑"
}
```

放入 `watch/` 后 3 秒内自动开始处理。全部成功 → `success/`；有失败 → `fail/` 并附 `result.json`。

### 定时发布

```json
{
  "title": "明日发布",
  "platforms": ["dy"],
  "account": "dy-01",
  "publish_at": "2026-08-12 08:00:00"
}
```

未到时间任务停留在 `pending/`，到点自动发布。

## 四、手动恢复 / 单次处理

调度服务异常退出后，重启时会自动继续处理 `pending/` 中的任务。也可以手动执行单次处理：

```bat
runtime\python.exe scheduler\main.py --once
```

## 五、自测

```bat
scripts\run_tests.bat
```

自测使用内置模拟 API，不联网、不真发视频，覆盖：

- 正常多平台发布 → success；
- 前两次失败、第三次成功 → 自动重试；
- 固定失败平台 → fail 目录 + result.json；
- 一成一败 → 部分成功，任务进 fail；
- 重复视频 → 去重，进 success/duplicate；
- 定时发布 → 到点自动发布。

## 六、日志与排障

- 运行日志：`logs/scheduler.log`（按天切割，保留 30 天）；
- 每个任务的发布明细：`fail/任务名/result.json` 或 `success/任务名/result.json`；
- 发布记录数据库：`data/tasks.db`（SQLite，可用任何 SQLite 工具查看）。

常见问题：

| 现象 | 处理 |
| --- | --- |
| 发布失败，提示未登录 / Cookie 过期 | 打开 MatrixMedia 重新登录对应平台 |
| 任务停在 pending/ | 检查 `publish_at` 是否在未来时间 |
| MatrixMedia 窗口打不开 | 删除 `%LOCALAPPDATA%\matrixmedia` 后重装 `matrixmedia/` 下安装包 |
| 平台页面改版导致失败 | 到 MatrixMedia 项目主页下载新版本替换 |

## 七、风险提示

- 自动化发布不符合部分平台服务协议，请低频、真实使用，避免批量刷量，账号风险自负；
- 小红书等平台对自动化检测较严，建议在 MatrixMedia 中开启「使用真实浏览器」模式；
- 敏感数据（账号、Cookie、日志、数据库）请勿公开分享。
